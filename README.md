# END OF HOPE: 21xx - Astral Eclipse

## プロジェクト概要

学校の1学年後期審査会に向けて制作した個人制作の3Dアクションゲームです。

制作期間は1か月。優秀賞をいただきました。

オリジナル創作『END OF HOPE: Universe』の1つの外伝というテーマで作成しています。

[動画](https://youtu.be/KkWmnPRRcm8)

## 目標

- アクションゲームとして手触りをよくするには？
- 無料アセットの組み合わせでもどこまでやれるか、補正などをしていくことでかっこよく見えるように。作品を愛する

## 学習内容

- Editor拡張
- 継承を理解（ベースクラス、インターフェース）
- インターフェースによる依存性注入
- InputAction
- InputBufferによるプレイヤーの入力情報の管理
- StateMachineBehaviourを継承しAnimatorに機能を追加するクラスを追加
- ShaderGraphでのエフェクト作成
- ステートパターンによるプレイヤーの状態管理
